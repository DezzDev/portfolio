## ⭐ Características

- **Diseño escuro** con paleta de colores en tonos azules
- **Efecto de partículas** flotantes en el fondo (Particles.js)
- **Animación de escritura** con palabras rotativas
- **Diseño responsive** adaptado para móviles y escritorio
- **Navegación fluida** con scroll suave
- **Efectos hover** en tarjetas y botones

---

## 🛠️ Tech Stack

| Tecnología | Descripción |
|------------|-------------|
| **HTML5** | Estructura semántica |
| **CSS3** | Variables CSS, Flexbox, Grid, Animaciones |
| **JavaScript ES6+** | Lógica interactiva |
| [Particles.js](https://vincentgarreau.com/particles.js/) | Fondo con partículas flotantes |
| [Google Fonts](https://fonts.google.com/) | Tipografía JetBrains Mono |
| [IconScout](https://iconscout.com/) | Iconos Unicode |
